# Recipe App MVP - Architecture Overview

## Core Components
1. **Frontend**: React Native (cross-platform mobile app)
2. **Backend**: Node.js with Express
3. **Database**: MongoDB (for recipe storage)
4. **API Services**: Recipe parsing, text extraction

## Data Flow
1. User captures recipe (image, URL, manual entry)
2. Text extraction/parsing service processes input
3. Structured recipe data stored in database
4. User can view, scale, and manage recipes
